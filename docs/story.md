# Project background

Nexus began as [Nexus4CC](https://github.com/librae8226/nexus4cc), developed by
librae8226, faywong and contributors to control local coding agents from a browser.
The [upstream story](https://github.com/librae8226/nexus4cc/blob/master/docs/story.md)
describes the original authors' motivation in their own words.

This repository is an independently maintained derivative by Jiang0977 and
contributors. Its work focuses on a Rust runtime, terminal recovery, desktop
split panes and self-hosted operation from desktop and mobile browsers.
It remains a single-user tool. Tmux is the default stable backend; native is an
opt-in path. See [README](../README.md) for current capabilities and
[LICENSE.md](../LICENSE.md) for attribution and GPL-3.0-or-later distribution terms.

Personal anecdotes and contact details from the original story are not presented
as the current maintainer's identity or support channel. Use this repository's
Issues for ordinary questions and SECURITY.md for vulnerabilities.
