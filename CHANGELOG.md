# Changelog

## 4.5.0 — 2026-09-10

First public release of this independently maintained Nexus4CC derivative.

- Rust HTTP/WebSocket runtime with tmux as the default terminal backend.
- Opt-in native PTY state checkpoints, reconnect recovery and shared sizing.
- Desktop split panes, mobile terminal controls, file browser and prompt library.
- Codex/Claude profiles and Codex history/resume.
- Complete first-install binary build, credential-only setup and password reset.
- User/system service scope selection for restart and source deployment.
- English and Chinese onboarding, explicit host-permission security guidance.
- GPL-3.0-or-later attribution and Linux x86_64 release packaging with checksums
  and corresponding source.

Earlier tags are development history, not supported public releases of this fork.
